# Duplicate File Cleaner & Log Automation

A Python-based automation script designed to detect and delete duplicate files from a directory using checksum-based duplicate detection and generate logs of operations performed.

## Features

- Detects duplicate files using checksum/hash-based comparison.
- Deletes duplicate files automatically.
- Generates logs of file operations.
- Uses scheduling for periodic execution.
- Sends email notifications for audit purposes.

## Tech Stack

- Python
- OS Module
- Hashlib
- Schedule
- Smtplib
